# Academic Support Chatbot

Demonstrate intent recognition for academic advising, instructors and registrar questions.

## Technical approach

Use Rasa DIET classification and training examples for course information, transcripts, billing and address updates.

## Technologies

Rasa, Python, YAML

## Project materials

- Application source and configuration files in this repository.

## Getting started

Inspect source-code/requirements.txt and configuration. The domain YAML appears to contain an indentation error and dialogue rules are not supplied; training and execution are not verified. The uploaded folder was called Medical Chat Bot, but the actual source concerns academic support.

For notebooks, use a compatible Python/Jupyter environment and install the imported libraries. Original environment-specific paths may need local adjustment.
